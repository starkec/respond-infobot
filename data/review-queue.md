# Infobot v2 review queue

V2 history has not been initialised yet. The first enabled live run imports the
existing bot history and baselines the feeds without publishing old articles.

After that run, this file lists live review holds and pending manual approvals.
Use **Actions > Infobot v2 > Run workflow > review** on **main** to approve or
reject a listed article. Supply its URL and a note explaining the decision.

A review action publishes nothing. Approved articles join the next live run,
subject to publisher image and duplicate checks. You can also explicitly review
a preview-only article while it remains in a configured RSS feed.

See [the operating instructions](../V2.md#review-and-approve-or-reject-a-held-story).
